# archdostudio

Website portfolio studio arsitektur & interior. Next.js (Pages Router) + MUI.

```bash
yarn install   # atau: npm install
yarn dev       # buka http://localhost:3000
```

- Teks, email, dan menu: `src/data/site.js`
- Daftar karya: `src/data/projects.js` (foto taruh di `public/images/projects/`)
- Warna dan font: `src/theme/theme.js`
